# my-awesome-copilot

Selfishly opinionated GitHub Copilot agents, instructions, and skills.

This is not a fork of any canonical "awesome" list. It's a public notebook of the patterns I actually use.
If someone else finds it useful, great.

## Structure

- `instructions/` — rules of engagement (style, constraints, conventions)
- `agents/` — agent specs (Promptly, Maestro, Architect, Coder, etc.)
- `skills/` — repeatable problem-solving playbooks + examples (`/pull-request`, etc.)
- `.github/instructions/` — authoring guides for the files in this repo (agents, skills)
- `.github/skills/` — repo-scoped meta-skills (e.g. scaffolding new skills)
